# 시뮬레이션 랜덤화 + thermal 보정: 알려진 한계

`sim/randomization-thermal-calib` 브랜치 작업 중 확인된 한계를 기록합니다.

## 액체 수위 선이 96×96에서 매우 작음

- 96×96 이미지에서 유리는 약 21–27픽셀(세로 7–8줄, 가로 3–4열)입니다. 기본 장면, seed 0–9로 측정했습니다.
- 액체 온도가 유리 온도와 다르면 thermal에 가로 수위 선이 생깁니다. 다만 수위 차이(0.33 / 0.5 / 0.67)는 1–2줄 정도의 차이로만 나타납니다.
- Thermal은 120×160에서 3×3 blur를 거친 뒤 96×96으로 줄이기 때문에, 경계가 더 흐려집니다.
- 그래서 정책이 수위 자체를 구분하기는 어렵고, "유리 아랫부분이 액체 온도 쪽으로 바뀐다" 정도의 신호로 보는 것이 맞습니다.
- 카메라 위치/시야각(`front_cam`, fovy 60)이나 이미지 크기를 바꾸지 않는 한 해결되지 않습니다. 둘 다 이번 작업 범위 밖입니다.

## 액체 원기둥 윗면이 유리 온도로 보임

- MuJoCo 유리는 닫힌 원기둥이라, 위에서 비스듬히 보이는 윗면은 액체 수면이 아니라 유리 온도로 렌더링됩니다.
- 실제 열린 컵이라면 수면(물의 방사율 약 0.96, 액체 온도)이 보입니다.
- Thermal 보정 리포트의 "맞출 수 없는 효과" 목록에도 같이 적을 예정입니다.
